# 用一条学习主线组织多篇笔记

用于需要拆篇、已有笔记零散或需要具体示例的情况。下文是结构示例，不是用户真实经历；其中的经历必须用实际材料替换，不能照抄成“我做过”。

## 先区分“学过哪些点”和“为什么一路学到这里”

碎片化清单只能回答前者：函数、变量、printf、编译器、地址、指针。

一条主线则说明它们如何发生联系：

> 起点是想理解函数四种形式。要知道返回值怎么被接住，先分清变量名与保存的值；要知道为什么没有屏幕输出，再分开 return 与 printf。为了验证例子，建立编译运行环境。继续学到指针时，把之前的“值”扩展为“值与位置”，最后区分 p、&p、*p。

这里的“为了、先、再、继续”必须对应真实学习材料。若实际次序不同，按真实过程叙述；若只是知识依赖，明确说是“复习顺序”，不要伪装成历史。

## 文件数量由需要决定

| 材料情况 | 合理组织 | 避免 |
| --- | --- | --- |
| 只澄清一个疑问 | 一篇笔记，带原想法与修正 | 同时新建目录、专题、日报、错题、索引 |
| 一次学习涉及几个强关联问题 | 一篇主线，必要处链接现有专题 | 因每个小标题都能独立命名就拆文件 |
| 多次学习积累出可复习专题 | 主线保留转折摘要，专题存完整解释 | 把同一完整解释复制进每次回顾 |
| 多学科共享前置知识 | 放到现有通用基础区或主学科的课前基础，其他课程链接 | 按来源课程重复建同名概念 |

不要把“每篇只讲一个知识点”机械地理解为每个符号必须单独成篇。主线回顾是一个独立用途，不必把它拆成零散事件文件。

## 主线页的可选骨架

按实际材料选用，不强制栏目齐全：

```text
本次我原本要解决的问题
    ↓
关键转折一：我的原想法 → 卡点 → 澄清后的理解
    ↓ 为什么需要再补下一点
关键转折二：沿用同一例子，改变一项条件
    ↓
实际做过的操作或验证，与未做的部分
    ↓
当前理解边界，以及紧接着的一项练习
```

主线页可以不包含所有代码细节，但读者不点链接也应能理解整段学习旅程。专题链接是深入入口，不承担被省略掉的叙事逻辑。

## 专题页的入口与出口

示意：

> **为什么到这里：** 为了看懂“p 保存地址”，我要先分清变量的内容和位置。
>
> **本页解决：** 用同一张图解释 a、&a、p、&p、*p；完整代码和详细错因只放在本页。
>
> **带走什么：** p 的内容是地址，&p 是自身位置，*p 访问所指对象。
>
> **下一步联系：** 理解这点后，再看为什么能通过 *p 改变 a；如果这个问题也在本页，就直接写下一段，不强制另建文件。

入口、出口用简短自然的过渡即可，不要求固定写这四个标题。链接文字尽量带原因，例如“回看我曾把 p 与 &p 填反的地方”，而非只放一串文件名。

## 速查层与详细层各负责一件事

- 开头摘要负责唤回整条主线，通常一小段即可。
- “我记得当时问过……”导航只收最有辨识度的疑问，指向准确的专题或章节。细项过多时按当前问题分组，不做一张无限增长的大表。
- 具体解释用一个熟悉的例子逐步推进；若图已经讲清位置关系，正文补读图方法，不重复抄一张同内容表。
- 长原始作答、完整试题和诊断输出必要时折叠或留作附件；当前会影响正确理解的限制不能藏起来。

## 如何处理既有的“质量好但很散”

1. 先找到这组笔记共同服务的真实问题；无法归入主线的独立问题留作分支，不硬接。
2. 为重复内容确定正文归属；其他位置保留经历摘要与链接。保留用户有辨识度的原话与错因，不用概括把它们抹平。
3. 补上缺失的因果过渡与前置依赖说明，而不是再添加一层总目录。
4. 检查是否存在只有索引入口、没有上下文的专题；给它一句“为什么需要这一页”。
5. 整理后从主线开头实际读一遍：下一段为何出现、图解释哪个疑问、读完能带走什么，应当清楚。

用户只请求创建或优化 skill 时，不据此直接重组现有知识库。上面的调整用于以后已授权的笔记整理工作。

## 增量整理与状态变化

新一轮学习优先接上已有主线的未解问题。若有独立目标，再建立新的主线。更新“掌握状态”时保留以前的错误与当时日期，不把旧记录改成从一开始就正确。

例如：之前只能填空，后来能独立写出并实际运行，应新增这次证据，注明当前状态提升；若只是整理者验证了例子，不能据此升级用户状态。

## 写作后自检的反例

- “我终于战胜了恐惧”：没有用户自述时，这是虚构情绪。
- “我今天独立完成了全部代码”：只有截图或整理者运行结果时，这是证据越界。
- 五篇专题都重复讲 return 与 printf：这应收敛为一个正文归属。
- 每篇结尾都有“下一步学指针”，但主线没有说明为何学指针：这仍是链接堆砌。
- 只留下红字错误，纠正在另一篇深处：容易让复习者重新记住错误。
- 一次简单澄清生成八篇文件：不是复用方法，而是在复刻某次交付的体积。
